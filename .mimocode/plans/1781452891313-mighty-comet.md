# Plan: Termius-Style Snippet Visual Window

## Goal
Replace the current snippet popup dialog (`SnippetTreeDialog`) with a floating visual window panel that looks like Termius's snippet panel — dark theme, categories, search, "New Snippet" button, and snippet items with command previews.

## Files to Create

### 1. `src/main/kotlin/app/termora/snippet/SnippetVisualWindow.kt` (NEW)

A `VisualWindowPanel` subclass that shows the Termius-style snippet panel.

**Layout (top to bottom inside the visual window):**
```
┌──────────────────────────────────────┐
│  Snippets                    [pin][x]│  ← VisualWindowPanel toolbar
├──────────────────────────────────────┤
│  [ + New Snippet ]                   │  ← Green accent button
├──────────────────────────────────────┤
│  [🔍 Search snippets...    ]         │  ← FlatTextField with find icon
├──────────────────────────────────────┤
│  All │  Recent │  Pinned             │  ← JToggleButtons (tab switches)
├──────────────────────────────────────┤
│  ▶ System admins           (12)      │  ← Folder row (collapsible)
│    production-server  sudo apt...    │  ← Snippet row (name + preview)
│    staging-server     docker...      │
│  ▶ DevOps                  (5)       │
│    deploy-script      kubectl...     │
│  ▶ Unsorted                 (8)      │
│    random-cmd         echo...        │
└──────────────────────────────────────┘
```

**Key implementation details:**
- Extends `VisualWindowPanel("Snippet", visualWindowManager)` + `Resumeable`
- Registers with tab via `Disposer.register(tab, this)`
- `title = I18n.getString("termora.snippet.title")`
- `getWindowName() = "Snippet"` for resume support
- Preferred size: `Dimension(360, 500)`
- Uses `DefaultListModel<Snippet>` + `JList<Snippet>` for the snippet list
- Custom `DefaultListCellRenderer` with two-line rendering:
  - Line 1: `Icons.codeSpan` icon + snippet name (bold)
  - Line 2: Command text preview (truncated to ~40 chars, muted color, smaller font)
  - Folder rows: `Icons.folder` icon + name + count (right-aligned)
- `FlatTextField` for search with `Icons.find` leading icon
- Three `JToggleButton` tabs: All, Recent, Pinned (using existing icons: `Icons.folder`, `Icons.history`, `Icons.pin`)
- "New Snippet" button: green accent background, white text, opens existing `SnippetDialog` for full management
- Double-click on snippet: calls `SnippetAction.getInstance().runSnippet(snippet, writer)` then focuses terminal
- Right-click context menu: Edit (opens SnippetDialog), Delete, Run
- Folder collapsing: `MutableSet<String>` tracks expanded folder IDs; clicking folder toggles expand/collapse
- Data loaded from `SnippetManager.getInstance().snippets()`, filtered by search text

## Files to Modify

### 2. `src/main/kotlin/app/termora/terminal/panel/vw/extensions/SnippetVisualWindowActionExtension.kt`

Change from popup dialog to visual window pattern:

```kotlin
// BEFORE: creates SnippetTreeDialog popup
// AFTER: creates SnippetVisualWindow visual window

override fun createActionButton(visualWindowManager: VisualWindowManager, tab: TerminalTab): AnAction {
    if (tab !is PtyHostTerminalTab) throw UnsupportedOperationException()
    return object : AnAction(Icons.codeSpan) {
        init { putValue(SHORT_DESCRIPTION, I18n.getString("termora.snippet.title")) }
        override fun actionPerformed(evt: AnActionEvent) {
            val vw = SnippetVisualWindow(tab, visualWindowManager)
            visualWindowManager.addVisualWindow(vw)
        }
    }
}

override fun getVisualWindowClass(tab: TerminalTab): Class<out VisualWindow> {
    return SnippetVisualWindow::class.java
}
```
